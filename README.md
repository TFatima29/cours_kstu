# Course Platform

Веб-платформа онлайн-обучения: каталог курсов, запись на курс, уровни с видеоуроками,
тест в конце каждого уровня, прогресс и сертификат. Наполнение — через панель администратора.

Командный проект по дисциплине «Командная разработка», КГТУ им. И. Раззакова, ПИ(б)-2-24:
Акматалиева Нургуль, Токсонбаева Фатима.

## Быстрый запуск (Windows, для разработки)

Нужен Python 3.11 или новее.

```bat
cd course_platform
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Откройте http://127.0.0.1:8000

На macOS / Linux вместо `.venv\Scripts\activate` используйте `source .venv/bin/activate`.

### Почта: логины и пароли студентам, восстановление пароля

Без настроек письма не отправляются, а печатаются в консоль, где запущен `runserver`.
Для настоящей отправки создайте файл `.env` рядом с `manage.py` (он не попадает в Git) и укажите SMTP:

```
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USE_TLS=1
EMAIL_HOST_USER=ваша.почта@gmail.com
EMAIL_HOST_PASSWORD=пароль-приложения-из-16-символов
```

Для Gmail нужен «пароль приложения» (Аккаунт Google → Безопасность → Двухэтапная проверка → Пароли приложений).
Mail.ru и Яндекс: `EMAIL_HOST=smtp.mail.ru` или `smtp.yandex.ru`, `EMAIL_PORT=465`, `EMAIL_USE_TLS=0`, `EMAIL_USE_SSL=1`.
После изменения `.env` перезапустите сайт.

## Панель администратора

- **Курсы** — создание, изменение, удаление; у курса есть цена в сомах (0 — бесплатно). Оплаты на сайте нет.
- **Материалы** — общая библиотека видео и файлов. Материал загружается один раз и подключается к любым урокам
  (видео урока или файлы к уроку выбираются на странице урока).
- **Студенты** — добавление студента по e-mail: логин и пароль генерируются автоматически и уходят на почту.
  При добавлении отмечаются курсы, которые студент купил. Изменение имени, e-mail, логина и пароля,
  новый пароль с отправкой на почту, блокировка и активация, удаление, выдача и отзыв доступа к курсам.
- **Отчёты** — таблица по студентам (курсы, прогресс, сданные тесты, средний балл) с выгрузкой в Excel и PDF,
  можно отфильтровать по курсу.

## Кабинет студента

- **Каталог** — все опубликованные курсы с ценами. Уроки и тесты открываются только в курсах, к которым администратор выдал доступ.
- **Мои курсы** — курсы с выданным доступом; на странице курса — обсуждение, под уроками — комментарии.
- **Тесты** — отдельный раздел со всеми тестами доступных курсов: статус, порог, лучший результат, число попыток.
- **Мой прогресс** — процент прохождения и результаты тестов.

## Варианты оформления

На сайте четыре варианта внешнего вида. Переключатель — в подвале любой страницы, выбор хранится в сессии.
Вариант по умолчанию задаётся переменной окружения `SITE_THEME` (route, ice, track, studio).

| Вариант | Референс | Идея |
|---|---|---|
| Маршрут (`route`) | — | Обучение как маршрут: уровни — станции на линии. Светлая и тёмная темы. |
| Лёд (`ice`) | igloo.inc | Каждый курс — 3D-кристалл (three.js), чем больше уроков, тем он крупнее. Наведение показывает курс, клик открывает. |
| Трасса (`track`) | landonorris.com | Курс — гоночная трасса: уровни — секторы, уроки — повороты. Выберите курс — трасса перерисуется, машинка едет круг. Светлая и тёмная темы. |
| Студия (`studio`) | activetheory.net | Каталог-шоурил на фоне живой WebGL-жидкости; наведение на курс перекрашивает фон в его цвет. |

Все шрифты и three.js лежат в `static/` — сайт работает без интернета. При `prefers-reduced-motion` анимации останавливаются,
без WebGL показывается статичный фон.

Файлы вариантов: `static/css/themes/<вариант>.css`, `static/js/themes/<вариант>.js`, `templates/themes/<вариант>/`
(hero.html — первый экран каталога, course_list.html — список курсов, cover.html — обложка курса без картинки).

## Дополнительные функции (раздел 4.1.3 ТЗ и сверх него)

- Категории курсов и уровень сложности, фильтры в каталоге; управление категориями в панели администратора.
- Обсуждение под уроком: вопросы, ответы, удаление своих комментариев, скрытие комментариев администратором.
- Уведомления: открыт новый уровень, курс пройден, ответили на комментарий, опубликован новый курс.
- Проверка подлинности сертификата по номеру: `/certificates/verify/`.

## Правила обучения

- Курс → уровни → уроки. Каждый уровень завершается тестом.
- Урок засчитывается автоматически после просмотра 90% видео (учитывается реально просмотренная часть,
  перемотка в конец не засчитывается). Урок без видео отмечается кнопкой «Урок изучен».
- Тест открывается после просмотра всех уроков уровня. Ответы проверяются только на сервере,
  правильные варианты в браузер не передаются.
- Следующий уровень открывается, когда тест сдан не ниже порога (по умолчанию 80%, задаёт администратор).
  Если в уровне нет вопросов, он считается пройденным после всех уроков.
- После последнего уровня курс отмечается пройденным и выдаётся сертификат (страница для печати / PDF).
