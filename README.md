# Course Platform

Веб-платформа онлайн-обучения: каталог курсов, запись на курс, уровни с видеоуроками,
тест в конце каждого уровня, прогресс и сертификат. Наполнение — через панель администратора.

Командный проект по дисциплине «Командная разработка», КГТУ им. И. Раззакова, ПИ(б)-2-24:
Акматалиева Нургуль, Токсонбаева Фатима.

## Быстрый запуск (Windows, для разработки)

Нужен Python 3.11 или новее.

```bat
cd course_platform
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Откройте http://127.0.0.1:8000

На macOS / Linux вместо `.venv\Scripts\activate` используйте `source .venv/bin/activate`.

|---|---|---|

Панель администратора: http://127.0.0.1:8000/manage/
Стандартная админка Django (для отладки): http://127.0.0.1:8000/django-admin/

Свой администратор: `python manage.py createsuperuser`.

### Письма восстановления пароля

В режиме разработки письма не отправляются, а печатаются в консоль, где запущен `runserver`.
Скопируйте ссылку из консоли в браузер. Для настоящей отправки укажите SMTP в `.env` (см. `.env.example`).

## Запуск на сервере (Docker)

```bash
cp .env.example .env      # поменяйте SECRET_KEY и пароли
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
```

Сайт откроется на 80-м порту. Состав: PostgreSQL, Django + Gunicorn, Nginx (раздаёт статику и видео).

## Тесты

```bash
python manage.py test
```

20 автотестов проверяют регистрацию, вход заблокированного пользователя, восстановление пароля,
открытие уровней, проверку теста на сервере, порог прохождения, сертификат и права администратора.

## Правила обучения

- Курс → уровни → уроки. Каждый уровень завершается тестом.
- Урок засчитывается автоматически после просмотра 90% видео (учитывается реально просмотренная часть,
  перемотка в конец не засчитывается). Урок без видео отмечается кнопкой «Урок изучен».
- Тест открывается после просмотра всех уроков уровня. Ответы проверяются только на сервере,
  правильные варианты в браузер не передаются.
- Следующий уровень открывается, когда тест сдан не ниже порога (по умолчанию 80%, задаёт администратор).
  Если в уровне нет вопросов, он считается пройденным после всех уроков.
- После последнего уровня курс отмечается пройденным и выдаётся сертификат (страница для печати / PDF).
